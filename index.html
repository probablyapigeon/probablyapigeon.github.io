OPEN THE HOOD / LIVE STUDY

The same present can carry a different past.

Run two operator paths from the same starting state. The traces converge near the center, but memory changes how each path responds to the next perturbation. This is an illustrative JavaScript animation of the idea. Its paths and readouts are illustrative, not measured XC execution or research results.

order_field.xc
# XC 0.1 — order is part of the model
model OrderField {
  seed 17701
  state z: vector[2] = [0.12, 0.34]
  memory trace: vector[32] decay=0.92

  operator F(x) { return rotate(x, 0.42) }
  operator V(x) { return tanh(x + [.18, -.08]) }

  pipeline FV { F -> V }
  pipeline VF { V -> F }

  metric order_effect = norm(FV(z) - VF(z))
  trace { z, trace, order_effect }
}

ABOUT THE HUMAN / HELLO

My process begins with “wait… is that actually true?”

Then I turn the question into math, turn the math into a simulation, attack the simulation, and keep whatever survives.

I’m a self-directed researcher and builder working across computational models of agency, language design, local AI, interactive art, and the philosophy of complex systems. I care about making ambitious ideas inspectable—especially when they begin as intuition.

Curiosity is the engine. Falsification is the steering wheel. The weird glowing visuals are non-negotiable.
01

Show the machinery. State, memory, operators, and assumptions belong where people can inspect them.

02

Name the boundary. A simulation can demonstrate its own math without proving a claim about nature.

03

Keep the wonder. Rigor should sharpen imagination, not flatten it.
