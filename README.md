# Kiersten Lynd / probablyapigeon

Personal portfolio: **https://probablyapigeon.github.io/**

This repository publishes the portfolio website using GitHub Pages from `main`.
It contains the static website and its downloadable XC examples. The XEMBRA
implementation remains in its separate repository.

To update the site, edit `index.html`, `portfolio.css`, or `portfolio.js` here.
Changes pushed to `main` are deployed by GitHub Pages automatically.

The browser visualizations are illustrative JavaScript demos. Their displayed
readouts are not measurements from an XC interpreter or research results.
